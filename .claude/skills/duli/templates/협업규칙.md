# AI 협업 규칙 (둘이검토 기본판)

이 파일은 둘이검토(duli) 스킬이 처음 설정 때 복사해 준 기본 규칙이다. 내 상황에 맞게 고쳐 써도 된다. AI는 작업을 시작하기 전에 이 파일을 읽는다.

## 폴더

- AI끼리 파일을 주고받는 곳은 `live_collaboration` 폴더다. 다른 컴퓨터나 다른 AI와의 인계도 여기서 찾는다.
- 이전 판은 `live_collaboration\백업`에 `… vN.md`로 둔다. 파일을 고치기 전에 먼저 백업한다.
- 비밀번호·API 키·.env·고객 개인정보가 담긴 파일은 공유 폴더에 넣지 않는다.

## 파일 이름

`<프로젝트> <순번> <할 일> → <받을 AI> - YYYY-MM-DD HHMM <쓴 AI>.md`
예: `대시보드 피드백 03 합친 글 검토 요청 → GPT - 2026-10-07 1330 Claude.md`

- 순번은 프로젝트 안에서 01부터 올라가고, 누가 쓰든 같은 번호 줄을 이어 쓴다.
- 화살표 "→" 대신 "to"를 써도 된다.
- 상대 AI가 쓴 파일은 고치지 않는다. 답은 새 파일로 쓴다.

## 사실을 적는 법

- 사실에는 표시를 붙인다. **[확인]** 공식 문서나 실제 파일을 직접 봄 · **[2차]** 남이 쓴 자료나 상대 AI의 보고 · **[추정]** 근거를 토대로 한 제안 · **[미확인]** 확인하지 못함.
- 사용자와 제3자의 감정·의도·성과를 추측해 적지 않는다.
- 실행 결과·선택 이유를 지어 채우지 않는다. 안 한 것은 안 했다고 쓴다.
- 날짜는 추정하지 말고 명령으로 확인한다.

## 답 파일에 늘 넣는 것

한 일 / 증거(경로·근거·출처) / 확인 못 한 것 / 판단이 갈리는 것(선택지 + 추천 + 근거).

## 두 AI가 같이 일할 때

- 한 폴더에서는 한 번에 AI 하나만 파일을 고친다. 상대가 고치는 중인 파일은 읽기만 한다.
- 의견이 갈리면 사용자에게 묻지 않고 "토론" 파일에서 근거로 끝낸다. 새 근거가 없으면 "새 근거 없음"이라고 쓴다.
- "완료" 파일이 오면 폴더 확인을 멈춘다.

## 사용자만 하는 것

게시·발송·삭제·배포. AI는 완료 파일까지만 만든다.
